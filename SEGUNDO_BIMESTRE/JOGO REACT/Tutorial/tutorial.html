Tutorial React: Clone do Termo

Aprenda a construir um jogo clássico de adivinhação de palavras (como o Termo ou Wordle) do zero, entendendo conceitos de Estado (State) e Efeitos (Effects) no React.

O que vamos construir?

Neste tutorial, vamos criar um mini web game onde o jogador tem 6 tentativas para adivinhar uma palavra de 5 letras. As regras são simples:

  • Letra Verde: Letra correta no lugar correto.
  • Letra Amarela: Letra existe na palavra, mas no lugar errado.
  • Letra Cinza: Letra não existe na palavra.

Passo 1: Setup do Projeto

Começaremos criando a base do nosso projeto React. Abra seu terminal e rode o seguinte comando para criar a estrutura inicial (vamos usar o Create React App ou Vite, aqui exemplificaremos com Vite pela velocidade):

npm create vite@latest projeto-termo -- --template react
cd projeto-termo
npm install
npm run dev
Nota: Este tutorial presume que você já tem o Node.js instalado na sua máquina.

Passo 2: Estrutura do Tabuleiro e Estilos

Nosso jogo precisa de uma grade (Grid) de 6 linhas por 5 colunas. Substitua o conteúdo do seu App.css para criarmos os estilos das caixas e as cores de feedback:

Passo 3: Construindo a Lógica Principal (App.jsx)

No arquivo App.jsx, precisaremos controlar três estados principais:

  1. solution: A palavra secreta que o jogador precisa adivinhar.
  2. guesses: Um array que guarda o histórico das palavras já tentadas.
  3. currentGuess: A palavra que o jogador está digitando no momento.

Vamos capturar a digitação do usuário usando o hook useEffect escutando o evento de teclado (keydown).

import React, { useState, useEffect } from 'react';
import './App.css';

const SOLUTION = "REACT"; // A palavra secreta

function App() {
  const [guesses, setGuesses] = useState(Array(6).fill(null));
  const [currentGuess, setCurrentGuess] = useState('');
  const [isGameOver, setIsGameOver] = useState(false);
  const [turn, setTurn] = useState(0);

  useEffect(() => {
    const handleKeyup = ({ key }) => {
      if (isGameOver) return;

      if (key === 'Enter') {
        if (turn > 5 || currentGuess.length !== 5) return;
        
        const newGuesses = [...guesses];
        newGuesses[turn] = currentGuess;
        setGuesses(newGuesses);
        setTurn(turn + 1);
        
        if (currentGuess.toUpperCase() === SOLUTION) {
          setIsGameOver(true);
          alert('Você venceu!');
        } else if (turn === 5) {
          setIsGameOver(true);
          alert('Fim de jogo! A palavra era: ' + SOLUTION);
        }
        setCurrentGuess('');
      }
      
      if (key === 'Backspace') {
        setCurrentGuess(prev => prev.slice(0, -1));
        return;
      }

      if (/^[A-Za-z]$/.test(key) && currentGuess.length < 5) {
        setCurrentGuess(prev => prev + key.toUpperCase());
      }
    };

    window.addEventListener('keyup', handleKeyup);
    return () => window.removeEventListener('keyup', handleKeyup);
  }, [currentGuess, isGameOver, turn, guesses]);

  // Função para checar cor das letras
  const getLetterClass = (letter, index) => {
    if (!letter) return '';
    if (SOLUTION[index] === letter) return 'correct';
    if (SOLUTION.includes(letter)) return 'present';
    return 'absent';
  };

  return (
    <div className="App">
      <h1 style={{textAlign: 'center'}}>Termo Clone</h1>
      <div className="board">
        {guesses.map((guess, i) => {
          const isCurrentTurn = i === turn;
          const word = isCurrentTurn ? currentGuess.padEnd(5, ' ') : (guess || '     ');
          
          return (
            <div key={i} className="row">
              {word.split('').map((letter, j) => (
                <div key={j} className={`cell ${!isCurrentTurn && guess ? getLetterClass(letter, j) : ''}`}>
                  {letter.trim()}
                </div>
              ))}
            </div>
          );
        })}
      </div>
    </div>
  );
}

export default App;

Resumo do que aprendemos

Assim como no Jogo da Velha (Tic-Tac-Toe), dividimos a nossa interface em uma grade. Porém, em vez de passar um turno entre 'X' e 'O', nosso estado controla as tentativas (guesses) e re-renderiza a tela condicionalmente atribuindo classes CSS (correct, present, absent) com base na comparação entre a tentativa do usuário e a solução.

Desafio Extra: Tente componentizar a linha (Row) e a célula (Cell) em arquivos separados e adicionar um teclado virtual na tela!
